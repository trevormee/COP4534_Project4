# Project 4: Bin Packing

A C++ project for Data Structures and Algorithms II that solves the Bin Packing problem using multiple packing strategies.

The program reads item sizes from a text file, applies online and offline bin packing algorithms, compares their results against an optimal solution, and prints all output to the console.

Please refer to **UsersManual.pdf** in the root of this project for more detailed information and how to run the program.
